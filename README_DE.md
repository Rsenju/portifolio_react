## 🎯 Über das Projekt

Dieses Projekt ist ein **persönliches Portfolio**, das entwickelt wurde, um meine Projekte klar und modern zu präsentieren.

Es ist eine **Single Page Application (SPA)** mit flüssiger Navigation zwischen den Seiten (Start, Projekte, Über mich).

> Fokus auf UI/UX, sauberen Code und Best Practices im Frontend.

---

## ✨ Funktionen

- Navigation mit React Router  
- Startseite mit professioneller Präsentation  
- Projektübersicht mit Highlight-Projekt  
- Über mich mit Stack und Kontakt  
- Links zu GitHub und Live-Demos  
- Responsives und minimalistisches Design  
- Hohe Performance mit Vite

## 🚀 Installation

### Voraussetzungen
- Node.js 18+
- npm oder yarn

```bash
git clone https://github.com/your-username/portfolio-react.git
cd portfolio_react
npm install
npm run dev
````

---

## 📖 Nutzung

```bash
npm run dev      # Entwicklungsserver
npm run build    # Produktion Build
npm run preview  # Build Vorschau
```
