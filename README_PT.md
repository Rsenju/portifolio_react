## 🎯 Sobre

Este projeto é um **portfólio pessoal** desenvolvido com foco em apresentar meus projetos de forma clara, moderna e organizada.

A aplicação segue o conceito de **SPA (Single Page Application)**, proporcionando uma navegação fluida entre páginas como Home, Projetos e Sobre.

> Projeto focado em UI/UX, organização de código e boas práticas de desenvolvimento front-end.

---

## ✨ Funcionalidades

* 🧭 Navegação com **React Router**
* 🏠 Página inicial com apresentação profissional
* 📂 Página de projetos com destaque para projeto principal
* 👩‍💻 Seção "Sobre" com stack e informações de contato
* 🔗 Links para GitHub e deploy dos projetos
* 📱 Design responsivo e minimalista
* ⚡ Performance otimizada com Vite

---

## 🛠️ Tecnologias

**Frontend:**

* React 18 - Biblioteca UI
* React Router DOM - Roteamento SPA
* Tailwind CSS - Estilização
* Vite - Build tool

## 🚀 Instalação

### Pré-requisitos

* Node.js 18+
* npm ou yarn

### Passo a passo

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/portfolio-react.git

# Entre na pasta
cd portfolio_react

# Instale as dependências
npm install

# Inicie o servidor
npm run dev
```

---

## 📖 Uso

### Desenvolvimento

```bash
npm run dev      # Servidor local
npm run build    # Build para produção
npm run preview  # Visualizar build
```
