## 🎯 About

This project is a **personal portfolio** designed to present my work in a clean, modern, and structured way.

Built as a **Single Page Application (SPA)**, it provides smooth navigation between sections such as Home, Projects, and About.

> Focused on UI/UX, clean code, and front-end best practices.

---

## ✨ Features

- Navigation with React Router  
- Professional landing page  
- Projects showcase with featured project  
- About section with stack and contact  
- GitHub and live demo links  
- Responsive and minimal design  
- Fast performance with Vite  

---

## 🚀 Installation

### Requirements
- Node.js 18+
- npm or yarn

```bash
git clone https://github.com/your-username/portfolio-react.git
cd portfolio_react
npm install
npm run dev
````

---

## 📖 Usage

```bash
npm run dev      # Development server
npm run build    # Production build
npm run preview  # Preview build
```
